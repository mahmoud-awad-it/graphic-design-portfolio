# Graphic Design Portfolio

My personal design portfolio: a collection of my own design work, made in Canva, plus a website visual project. These are personal practice projects, not commissioned brand work, except where noted below.

Full portfolio (PDF): [Graphic_Design_Portfolio.pdf](Graphic_Design_Portfolio.pdf)

## Selected pages
1. **Malvano, logo concepts** (page-03.png): monochrome "MA" monogram in a circular form with a wordmark, dark and reversed versions.
2. **Malvano, brand display** (page-04.png): a simple brand lockup with a social handle, and a thank-you card concept.
3. **QR, Scan Now** (page-05.png): a promotional layout where the QR code is the focal point, with an arrow and a handwritten scan instruction.
4. **Fashion Store concept** (page-06.png): a yellow retail graphic with a hanger-inspired line symbol and a simple wordmark.

The PDF also shows the visual design of harbyezz.com, a website I built for a client. Its source is published in a separate repo.

Tool: Canva.
